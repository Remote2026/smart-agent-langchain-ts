# 人形机器人事业部（中国区）研究方向讨论提案

## —— 差异化突围：基于中国供应链的底层驱动集成与局部控制小脑平台

---

## 1. 战略定位与核心愿景

* **WHY（为什么这么定位）：**
在通用人工智能（AGI）浪潮下，总部的绝对优势在于“大脑（大模型认知与高阶行为规划）”的研发。然而，云端的算法再完美，如果没有高频、稳定、软硬解耦的物理神经系统作为支撑，在真实世界中就会陷入“高位截瘫”。同时，中国区团队不应投入重资产进行硬件制造，也不应与总部内卷高阶行为算法，而应发挥我们在**系统架构、嵌入式软件、以及中间件驱动**方面的核心软实力。
* **WHAT（我们定位成什么）：**
中国区团队的战略定位是：**公司具身智能系统的“首席底层系统软件集成商与小脑接口定义者”**。我们不造任何硬件零组件，不开设工厂，不碰高阶大模型；我们通过**编写高效的底层驱动、多传感器融合软件以及局部边缘闭环控制算法**，将中国成熟的供应链散件，驯化为总部大脑“通电即用、具备条件反射”的标准化智能身体。
* **HOW（我们如何实现）：**
将核心技术标签定义为：**【驱动定义硬件，软件赋能集成（Driver-Defined Integration & Edge-Control Software Platform）】**。我们采取轻资产、纯软件集成的模式，100% 聚焦于“智能家庭（Smart Home）”这一高难度场景，向下用软件控制硬件驱动，向上为总部的 AI 科学家交付标准、干净的触觉与力控 API。

---

## 2. 核心集成与驱动方向：多模态触觉灵巧手系统集成（末端神经系统软件定义）

我们聚焦于具身智能物理交互中最核心、最卡脖子的单一硬核痛点，将其做深做透：

* **WHY（客观需求与致命痛点）：**
目前的具身智能灵巧手在物理交互上面临两个致命的“软件与控制”死穴：
1. **大模型高延迟（High Latency）：** 总部云端的 VLA（视觉-语言-动作）大模型由于模型体量大、传输链路长，控制频率通常只有 **$10\text{ Hz} \sim 20\text{ Hz}$**（响应时间长达 50-100ms）。而物理世界的物体“微滑移”发生在毫秒之间，如果完全等待总部大脑做出重新抓取的决策，物体早就摔碎了。
2. **信号电磁噪声（EMI Noise）：** 供应链提供的微型空心杯电机在方寸之间全速运转时会产生极强的电磁干扰，导致指尖柔性触觉传感器传回的微伏级数据流全是“乱码和高频噪声”，总部的算法团队根本无法直接使用。


* **WHAT（我们交付什么）：**
一套运行在指尖 MCU 上的**高频去噪固件（Firmware）**与**边缘自适应抗滑移控制算法库**。该软件系统能将异构的供应链散件无缝、无噪地连接，并在边缘端实现自主条件反射控制。
* **HOW（我们如何通过系统与软件开发实现）：**
* **编写高频去噪驱动软件（向下控硬件）：** 跨界平移国内成熟的智能手机压力屏与消费电子供应链（如鸣志电机、能斯达传感器）。我们通过纯软件手段，在指尖嵌入式 MCU 中编写高频（$\ge 500\text{ Hz}$）数据采集与数字滤波算法（如卡尔曼滤波、时域去噪），从**软件层面彻底滤除电磁干扰**，将无法使用的硬件噪声转化为绝对干净、结构化的物理数据流。
* **调试边缘闭环控制软件（本地小脑自闭环）：** 在本地嵌入式层独立开发“条件反射式微滑移控制库”。当去噪驱动检测到剪切力异常的瞬时数据时，本地软件无需向上大模型汇报，直接在 **10 毫秒内** 在本地闭环下发加力驱动指令。这种“本地小脑软件负责高频抗滑移（$500\text{ Hz}$），总部大模型负责高阶行为规划（$20\text{ Hz}$）”的软硬件分层解耦架构，彻底解决了大模型的延迟死穴。
* **封装标准数据 API（向上接算法）：** 将所有触觉数据和边缘控制状态封装为标准的 ROS2 节点或 gRPC 接口。总部的 AI 科学家不需要懂任何底层电气与硬件细节，一句话（如调用标准的 C++ / Python / TypeScript 接口）就能直接调用经过中国区优化过的“高级手部触觉控制技能”。

## 3. 初步开发与 Demo 路线图（从 0 到 1）

通过高效的底层驱动开发与局部算法调试能力，在 3 个月内为总部快速交付成果，**不堆砌 PPT，直接用物理运行结果和数据说话**：

### Phase 1（1-2个月）：底层多路传感器驱动编写与去噪软件验证

* **WHY：** 证明中国区团队在极短时间内对异构触觉信号的软件驱动能力，以及纯软件治理电磁干扰（EMI）的硬核实力。
* **WHAT：** 一套高频、低延迟、输出绝对平滑干净的触觉数据流透传系统软件。
* **HOW：** 让灵巧手处于电机全速运转的高噪声环境下，通过我们编写的滤波驱动固件，在上位机实时可视化展示去噪前后的对比波形，证明我们能为总部大模型提供高保真的“干净神经末梢数据”。

### Phase 2（2-3个月）：弱光环境下的“深夜无噪自适应盲抓”系统验证

* **WHY：** 证明中国区“小脑边缘自闭环算法”的有效性，解决大模型高延迟导致物体摔落的行业痛点。
* **WHAT：** 一个断开所有摄像头、完全不依赖总部视觉与高阶行为算法的自适应控制软件实体。
* **HOW：** 模拟凌晨2点，灵巧手纯靠中国区编写的底层触觉驱动和本地自适应算法，在毫秒级内自主感知物体的微滑移并实时调整抓力，完美整理散落的家庭用品（毛绒玩具、陶瓷杯、纸盒），机械运行噪音严格控制在 $40\text{ dB}$ 以下。

## 4. 独特的非对称竞争优势（如何向高层汇报）

* **定位壁垒——不可或缺的“小脑与神经系统软件”**
* **WHY：** 纯硬件集成只是堆砌没有灵魂的零件，纯大模型研发只是无法在物理世界精细落地的空中楼阁。
* **WHAT：** 中国区团队做的是将两者缝合在一起的“控制驱动与小脑软件底座”。
* **HOW：** 我们做的是高频数字信号处理（DSP）、硬实时控制（Real-time Control）和边缘条件反射软件。没有我们的驱动优化，总部的“大脑”就无法指挥这具身体，我们在生态中具有不可替代的战略价值。


* **商业价值壁垒——实验室艺术品向消费级量产的“软件平替器”**
* **WHY：** 海外总部的方案往往是不计成本、无法量产的实验室高奢科研作品（依赖高价的进口专用硬件）。
* **WHAT：** 中国区集成团队的核心价值是用“聪明的软件驱动”来平替“昂贵的硬件”。
* **HOW：** 依托我们对中国庞大机电/电子供应链的熟悉度，利用软件算法去弥补国产工业级、汽车级组件在物理性能上的不完美（如用滤波算法治硬件噪声，用边缘控制补执行器迟滞），在不牺牲核心性能的前提下，将整体 BOM 成本砍掉 80% 以上，直接具备商业化量产可能。


* **资产极轻与敏捷速度——无工厂红利，硬件的“周级软件集成”**
* **WHY：** 传统硬件制造厂背负着沉重的生产线改造周期，海外研发机构采购加工周期漫长。
* **WHAT：** 我们不建厂、不造零件，人员精简，背负资产极轻，拥有全行业最敏捷的“迭代速度”。
* **HOW：** 依靠长三角/珠三角的现成组件配套，团队可以做到“白天改驱动代码和布线图，晚上直接采购市场上最新的国产组件散件，后天即完成总线调试并跑通数据”。这种软件定义集成的速度是任何海外团队无法复制的护城河。
