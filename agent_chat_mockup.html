V1
User
把客厅灯打开，亮度设为 40%，然后告诉我当前 ROS2 的 /robot_state 参数。
Assistant
我会先执行：SmartThings 打开客厅灯并设置亮度；然后通过 rosbridge 读取 ROS2 参数。执行中…
Tool Call
smartthings.setSwitch(deviceId=..., on=true)
smartthings.setLevel(deviceId=..., level=40)
Tool Call
ros2.getParam(node="/robot", name="robot_state")
Assistant
已打开客厅灯并设置亮度 40%。ROS2 参数 /robot_state 当前为：idle。
